## 01:48 Community News

### Project of the Week: A Game Boy Color Emulator on the GitHub Universe Badge

Steve Francia wrote a Game Boy and Game Boy Color emulator in MicroPython for the GitHub Universe 2026 badge, an RP2350 board with PSRAM and a 320x240 display. Viper-compiled code keeps each frame within the 60 Hz budget, so games like Link's Awakening DX and Pokémon Crystal play at native size, and the work also sped up the earlier NES emulator for the badge \- [spf13.com](http://spf13.com) and [GitHub](https://github.com/spf13/universe-2026-badge-hacks).

### 02:24 Unofficial CircuitPython Desktop Port

Maker Class has an unofficial fork of CircuitPython that adds a desktop port, so CircuitPython code and libraries run as a program on Linux, Windows or macOS. The terminal is the serial console, a window is the display, a folder is the CIRCUITPY drive, and real pins are available through an FT232H or MCP2221A USB adapter or a Raspberry Pi's header \- [GitHub](https://github.com/MakerClassCZ/cp-desktop-lab).

### 02:54 MP3 Cassette Player V2

Gammawave updates an MP3 player built into a 3D-printed cassette shell, now with a flexible PCB to cut down the wiring. An ESP32-C3 mini board with a built-in OLED display runs MicroPython, driving a DFPlayer Mini that feeds the tape head so the cassette plays in a regular tape deck \- [Instructables](https://www.instructables.com/MP3-Player-Cassette-V2).
