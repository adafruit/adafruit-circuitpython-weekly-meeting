## 2:48 Community News

### 2:56 openbricks \- Pybricks-style MicroPython Robot Firmware for ESP32

`openbricks` is an open-source (MIT) MicroPython firmware for ESP32-S3 that brings a Pybricks-style Python robotics API to commodity hardware — $15 serial-bus servos, a SPI IMU, reflectance arrays. The motor hot path runs at 1 kHz in native C inside the firmware: drivebase controller, trajectory planner, and gyro heading correction read inside the control tick (±0.2° per turn on our bench robot vs 3–5° encoder-only). Programs cross-compile on the host with mpy-cross and upload over BLE, and a MuJoCo-based simulator runs the same firmware API unchanged for hardware-free development \- [openbricks.dev](https://openbricks.dev/), [documentation](https://docs.openbricks.dev/) and [GitHub](https://github.com/1e0ng/openbricks).
