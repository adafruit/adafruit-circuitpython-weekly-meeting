## 2:43 Community News

### 2:57 CircuitPython displayio Now Runs on LVGL in Latest Alpha Versions on Select Chips

CircuitPython’s displayio now runs on the LVGL graphics library on ESP32-P4 and ESP32-S31 boards, in the Absolute Newest builds on circuitpython.org. Existing code works as is: Groups, TileGrids, Bitmaps, Palettes and vectorio shapes use the same API, with LVGL composing the screen. The new version is built for speed, and its internal formats are ready for the graphics accelerators in chips like the ESP32-P4. Audio keeps playing smoothly during screen redraws, and vectorio can now draw rounded rectangles, which need far less memory than bitmaps for dashboard-style widgets – [GitHub](https://github.com/adafruit/circuitpython/pull/11887).  
The speed costs RAM, so code that ran slowly before may now run out of memory, and a new safe mode says so when it happens. Other boards keep the original displayio – [GitHub](https://github.com/adafruit/circuitpython/pulls?q=is%3Apr+lvgl).

### 5:05 MicroPython v1.30 Is 84% Done, Still Targeting December 7th

The MicroPython v1.30 milestone on GitHub is now 84% complete, with 133 items closed and 25 open, and the release still targets December 7th. Preview builds already add positional-only parameters, asyncio.Queue, WiFi HaLow (802.11ah) networking, OpenMV camera boards, the STM32N6570-DK, hardware floating point on RP2350 boards and a browser build of the WebAssembly port, and mpremote now resumes a board’s session by default. A minimal typing module, asyncio TaskGroups and HSTX output on the RP2350 are still under review – [GitHub](https://github.com/micropython/micropython/milestone/14).
