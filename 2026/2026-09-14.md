## 1:52 Community News

### 2:10 An Incremental Garbage Collector For MicroPython

nunomo/raspy135 has added incremental garbage collection for MicroPython. It eliminates stop-the-world garbage collection which is one of the disadvantages of using MicroPython. It can keep high FPS in graphics applications with massive data allocations \- [GitHub](https://github.com/raspy135/micropython/tree/gc-incremental). Via [X](https://x.com/nunomo1/status/2097702464862794019).

- ATB expanded to 4bit  
- GC skips scanning for 'data' type such as bytearray.  
- GC can run partially in background, for scan and sweep.  
- ESP32 and unix port are available, easy to port to other boards.

### 3:29 CircuitPython Remote

CircuitPython Remote 0.0.2 is an early beta VS Code extension for browsing and editing files on CircuitPython Web Workflow devices over WiFi. It is designed around the standard CircuitPython Web Workflow API, but other boards, operating systems, firmware versions, and network configurations have not yet been verified. The author is looking for community feedback \- [Adafruit Forums](https://forums.adafruit.com/viewtopic.php?t=225016), code [Visual Studio Marketplace](https://marketplace.visualstudio.com/items?itemName=triplelrobotics.circuitpython-remote) and [GitHub](https://github.com/triplelrobotics/circuitpython-esp32-remote-dev).

### 4:04 Snakie Now Allows Picking a Microcontroller Board From a List of Nearly 240 Devices

Kevin McAleer's Snakie editor / integrated development environment (IDE) for MicroPython and CircuitPython now lets you pick the board to code for and flash from a catalog of nearly 240 boards \- [X](https://x.com/kevsmac/status/2096359153547522329) and [Snakie app](https://app.snakie.org/).
